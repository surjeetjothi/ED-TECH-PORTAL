User Management
 Objective
In the RBAC (Role based access control)  the user get the roles that match their responsibilities.
Organizations streamline access control by aligning users with roles rather than individual
permissions, making it easy to adjust when an employeeʼs role changes.

Product overview
Role-Based Access Control (RBAC) is a security approach that controls user access to IT
resources by assigning permissions to roles based on job functions. Instead of giving
permissions directly to users, RBAC links users to roles, granting only the access needed
for their tasks. This follows the least privilege principle, enhancing security and simplifying
management.
